## 当前版本：v1.0

## 背景与范围

在用户关注池（`data/watchlist_site.csv`）内，每日盘后识别两类共同内核的形态：**主力已深度介入、但股价尚未兑现**。回马枪捕捉单日爆发式介入后的回踩，蚂蚁吸筹捕捉多日持续均匀吸筹。

本指标只服务关注池，不承担全市场选股职责。资金流数据按单子大小分档（特大单/大单），无法识别交易者身份，结论为概率优势而非确定性信号。

## 数据模型

沿用既有表，不新增字段：

- `moneyflow(ts_code, trade_date)`：`buy_elg_amount`/`buy_lg_amount`/`sell_elg_amount`/`sell_lg_amount`（万元）
- `daily(ts_code, trade_date)`：`open`/`high`/`low`/`close`/`pre_close`/`amount`（千元）
- `daily_basic(ts_code, trade_date)`：`circ_mv`（万元）

派生量：

```
主力净额(万元) = buy_elg_amount + buy_lg_amount - sell_elg_amount - sell_lg_amount
成交额(万元)   = daily.amount / 10
```

已实测校验：`daily.amount / 10` 与 `moneyflow` 四档买入额之和恒等（如 002487.SZ 20260911 均为 246510 万元），故占比口径与市场通用"主力净流入占比"一致。

价格一律使用未复权原始价；回调窗口 ≤10 个交易日，除权概率低，暂不引入复权因子。

## 业务规则

### 指标一：主力回马枪

**介入日 D0 的成立条件**（两者同时满足）：

1. `主力净额 / 成交额 ≥ 12%`
2. `主力净额 ≥ 流通市值 × 0.3%`（兜底，防止小体量资金在小票上产生高占比假象）

**回调期**：D0 之后的第 1 至第 10 个交易日（含端点），逐日必须全部满足：

3. 任一日 `low ≥ D0.low`（不得跌破介入日最低价）
4. 任一日 `close ≤ D0.close × 1.03`（不要求必须下跌，横盘小涨均可，但不得明显上行）
5. 主力留存率 ≥ 70%：
   ```
   留存率 = (D0主力净额 + 回调期累计主力净额) ÷ D0主力净额
   ```
6. 单日熔断：任一日 `主力净额 ≥ -50% × D0主力净额`
7. 总涨幅约束：
   ```
   回调期最后一根收盘 ÷ D0.pre_close - 1 ≤ 15%
   ```

第 4 条与第 7 条不冲突的数学依据：介入日最大涨幅 10%（涨停）与回调期 3% 复合后理论上限为 `1.10 × 1.03 - 1 = 13.3% < 15%`。

**去重**：同一 `ts_code` 存在多个合格 D0 时，取最近一个。

### 指标二：蚂蚁吸筹

在最近 20 个交易日的滚动窗口内：

1. **持续性**：主力净流入天数 ≥ 11 天
2. **均匀度**：
   ```
   集中度 = max(窗口内单日主力净额) ÷ sum(窗口内净流入日的主力净额) ≤ 55%
   ```
   用于将"多日均匀吸筹"与"单日爆发式介入"区分开。
3. **三周期同向**：`f5 > 0` 且 `f10 > 0` 且 `f20 ≥ 1%`，其中
   ```
   fN = N日累计主力净额 ÷ N日累计成交额
   ```
4. **累积深度**：`20日累计主力净额 ≥ 流通市值 × 0.3%`
5. **未兑现**：`20日涨幅 ≤ 10%`（窗口末收盘 ÷ 窗口首收盘 - 1）

## 非目标

- 不做全市场扫描，不做板块拥挤度过滤
- 不做连续大幅流入时的涨幅放宽至 20%（后续优化项）
- 不改变既有 `turning_point` / `breakout_point` / `golden_bull_*` / `trend_pullback` 策略逻辑

## 回测验证与落地状态（v1.1，2026-09-18）

### 主力回马枪：不做历史回测，落地为每日候选推送

回马枪的实战确认依赖板块联动（同板块是否共振）与次日开盘竞价（主力是否真金白银承接），两者均无历史数据库，回测无法还原。2026-09-18 用户决策：放弃回测，改为每日盘后推送候选名单，板块与竞价由使用者人工把关。

- 生产脚本：`scripts/scan_horseback.py`（参数即本 spec，禁止改动；输出含命中明细与"候选仅供参考"脚注）
- 推送：QwenPaw cron「回马枪候选推送（交易日20:35）」，交易日 20:35 触发（20:10 market 组同步含 moneyflow，任务内含数据就绪校验），最终回复直接投递飞书
- 2026-09-17 验收：命中 4 只（中微公司/星网锐捷/世运电路/锐捷网络），与下方验收标准一致

### 蚂蚁吸筹：三种用法回测全部否决（2026-09-17/18，数据 2020-01~2026-09 全市场）

1. 叠加定稿起爆点 v2：全市场 3 年 27.6 万笔事件，同日匹配后超额胜率 −1.4%、均值 +0.12%（t=1.22 不显著）；15 个月口径的表面优势（+1.18%, t=1.83）经样本加倍后收敛到零，坐实为行情偏差
2. 独立使用：全市场 6131 个回马枪状态日 f5/f10/f20 零超额（t=0.62/1.67/−0.62）；蚂蚁吸筹 11.6 万状态日全部负超额
3. 市场温度计：吸筹票占比五分位与未来市场收益无单调关系且方向相反

### 蚂蚁吸筹 × 趋势回踩起爆 × core 业绩共振假设：否决（2026-09-18）

假设：蚂蚁吸筹需与业绩共振（core 白马）才能走出趋势反转/延续而非反弹。检验（core 87 只，2020-02~2026-09，买入=信号日收盘确认/涨幅>5%顺延，卖出=库 `IgnitionPosition` 现行规则）：

- **同日交集 = 0**：core 池 6.5 年蚂蚁吸筹状态日与 `trend_pullback` 信号日无一日重合。结构性原因：吸筹发生在底部横盘期（金牛通道常为空头），回踩起爆要求通道已转多，两者时间上错位。此外 core 白马（流通市值中位 254 亿）的特大+大单资金流是围绕 0 的双向对冲噪声，很难留下"20 日内 11+ 天持续净流入且累计达流通 0.3%"的痕迹——该形态天然属于中小盘
- 改为时序口径（吸筹状态出现在过去 W 个交易日内）：EXP40（W=40）361 笔，毛收益均值 +1.60%，对朴素基准超额 +1.00%（t=1.28 不显著），对无吸筹对照组同日配对差 +0.87%（t=0.72 不显著）
- 分年稳定性：2020 −0.31%、2021 +10.07%（由 5 笔赛道股极值支配：300604 两笔 +160%/+153%、300390 三笔 +65%，剔除极值后 +6.95% 仍集中于该年）、2022 +0.78%、2023 +0.48%、2024 −1.92%、2025 +0.16%、2026 +0.60%；各年超额为正比例多数不足 50%
- **结论：方向为正但无统计显著性，且极不稳定，不构成有效策略，不上线。**「资金流形态 × 业绩共振」假设在特大+大单资金流口径下不成立；若未来引入北向持股、融资余额等增量资金数据可重新评估
