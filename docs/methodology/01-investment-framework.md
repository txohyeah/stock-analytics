
# 产业投资框架

> 先看大局（美联储降息/利率周期），再定赛道（利率敏感+产业趋势），最后选个股（四层筛子），买入后持续跟踪产业边际变化，预设退出条件，形成闭环。

**与 Serenity Skill 的关系**：Serenity 是"自下而上从消息挖弹性标的"，本框架是"自上而下定赛道与核心持仓"。两者可以串联——先用本框架锁定产业方向，再用 Serenity 在选定赛道内挖小市值弹性。

---

## 入口 1：宏观定位（利率周期分析）

**匹配方式**：用户提到「宏观」「降息」「利率」「联储」「美债」「美联储」「赚钱效应」「流动性」等关键词时自动触发。

**流程**：

1. 获取当前关键数据：10 年期美债利率、联邦基金利率、CPI/核心 PCE、失业率、布伦特原油价格
2. 对照三类降息的区分标准（见 `references/macro-check.md`）判断当前处于哪一类：
   - **预防式降息** — 经济放缓迹象但通胀可控，美股表现较强
   - **衰退式降息** — 经济确认衰退，通胀已回落，美股呈现 N 型走势
   - **危机性降息** — 金融/突发危机，节奏快时间短，V 型反转
3. 识别当前的关键条件变量（如 2026 年的美伊战争→油价变量）
4. 输出情景分析：写出当前判定的核心依据，列出条件转换的边界

**示例输出结构**：

```
## 宏观定位分析

### 当前判定：[预防式 / 衰退式 / 危机性]
依据：[具体数据 + 推理]

### 关键条件变量
- [变量1]：[当前值] → [如果...则...]
- [变量2]：[当前值] → [如果...则...]

### 路径依赖
- 基准场景：[概率较高路径及影响]
- 条件转换场景：[触发条件及切换后的方向变化]
```

## 入口 2：降息传导链

**匹配方式**：用户提到「降息受益」「传导链」「受益板块」「板块优先级」「Tech→House→Resources」「传导顺序」等关键词时自动触发。

**流程**：

1. 根据当前宏观判定，输出降息受益的传导顺序：

```
科技 / 医药   →   地产 / 耐用消费品   →   资源品
（最先受益）       （传导次之）            （滞后但弹性大）
```

2. 拆解每个环节的 A 股映射：

| 板块 | 传导逻辑 | A 股映射 | 当前阶段判断 |
|------|---------|---------|------------|
| 科技/医药 | 融资成本下降，一级市场投融资回暖 | Biotech/创新药（XBI先行指标）、AI硬件（光模块） | [判断] |
| 地产/耐用消费品 | 长端利率回落→美国地产回暖→出口拉动 | 家电/家具/建材对美出口链 | [判断] |
| 资源品 | 降息需求改善+美元走弱 | 铜铝工业金属（注意油价变量） | [判断] |

3. 如果当前处于 2026 年美伊战争环境下，需特别标注油价对资源品内部的错位影响

## 入口 3：行业三维定性

**匹配方式**：用户提到「行业定性」「三维」「行业分析」「这个行业怎么样」等关键词，或明确表达想分析某个行业时自动触发。

**流程**：

对指定行业从三个维度打分：

```
维度 1：爆发式需求
- 行业需求是否在爆发增长？如 AI 训练算力需求
- 特征：增速最快，但也最拥挤

维度 2：存量技术变革
- 是否有明确的存量替代逻辑？如燃油车→新能源
- 特征：替代逻辑清晰，市场空间可测算

维度 3：参与者变化
- 行业格局是否突变？如地缘因素导致国产替代
- 特征：格局变局，通常有定价权溢价
```

**特别判断**：如果一个行业同时沾三个维度（如 AI 硬件），这是结构性强势的根本原因。

**输出示例**：

```
## 行业三维定性 — [行业名称]

| 维度 | 得分 | 依据 |
|-----|:---:|------|
| ① 爆发式需求 | ✅/⚠️/❌ | [依据] |
| ② 存量技术变革 | ✅/⚠️/❌ | [依据] |
| ③ 参与者变化 | ✅/⚠️/❌ | [依据] |

综合评价：[结论]
```

## 入口 4：四层筛子（个股评估）

**匹配方式**：用户提到「[股票名/代码] + 能不能买/值不值得/四层筛子/帮我看看/分析一下/评估」等组合时自动触发。这是最核心和最常用的入口。

**流程**：

对目标个股执行四层递进筛选（淘汰制，任一环节不通过则标记为不通过）：

```
① 卡脖子 / 格局壁垒
   → 是否具备全球竞争力的技术或市场壁垒？
   → 否决条件：无明确壁垒 / 靠低价抢份额 / 纯代工无技术

② 价值量最大 / 通胀逻辑
   → 该环节在产业链中的价值占比是否大？
   → 随技术升级价值量是否提升（而非被压缩）？
   → 否决条件：价值量被上下游挤压 / 技术升级反而稀释价值

③ 供需矛盾
   → 当前是否供不应求？
   → 大客户是否锁单？
   → 否决条件：产能严重过剩 / 无定价权

④ 利润弹性 + 壁垒延续
   → 未来 2 年利润弹性有多大？
   → 壁垒是否能维持 3-5 年？
   → 否决条件：利润可见性不足 / 壁垒延续时间短

④b 参股价值重估（补充分析，不参与淘汰）
   → 仅在母公司持有重要参股（≥10%）且参股标的有价值时触发
   → 参股标的自身是否有价值？核心赛道？有营收/盈利吗？
   → 隐含价值（母公司持股份额 × 参股标的合理估值）占母公司市值多大？
   → 价值解锁路径是否明确（IPO/分拆/融资中）？
```

**输出格式**：

```
## 四层筛子 — [标的名称]

### ① 卡脖子 / 格局壁垒 → ✅ / ⚠️ / ❌
[依据说明]

### ② 价值量最大 / 通胀逻辑 → ✅ / ⚠️ / ❌
[依据说明]

### ③ 供需矛盾 → ✅ / ⚠️ / ❌
[依据说明]

### ④ 利润弹性 + 壁垒延续 → ✅ / ⚠️ / ❌
[依据说明]

### ④b 参股价值重估 → ✅（有价值·加分） / ⚠️（待观察） / ➖（跳过·不适用）
[参股标的] — 持股 [X%]
- 参股标的价值判断：[赛道/营收/盈利概况 → 结论：有价值/待观察/无价值]
- 隐含价值（母公司份额）：XX 亿（占母公司市值 X%）
- 价值解锁路径：[IPO申报中/计划分拆/融资引战/暂无明确路径]
- 对整体结论的影响：[如参股标的有价值，则增强利润弹性判断；否则不改变结论]

### 综合判定
通过：四层全部通过
🔄 参股价值贡献：[加分显著 / 参考信息 / 不适用]
未通过：[说明在哪层被筛掉及原因]

### 补充：估值安全边际（第 5 个筛子）
当前 PE/市值：[数据]
隐含增长预期：[市场已定价了多少？]
安全边际评估：[高/中/低]
```

> **⚠️ 重要提醒**：若用户只问了估值或基本面对比（如"中际旭创 PE 多少"），直接用 tushare-data 查数据即可，不需要跑完整四层筛子。四层筛子是有分析成本的操作，不要在简单查询上滥用。

## 入口 5：红绿灯跟踪表

**匹配方式**：用户提到「红绿灯」「跟踪表」「盯持仓」「[股票名/代码] + 跟踪/预警/盯盘」「帮我设计跟踪指标」等关键词时自动触发。

**流程**：

1. 判断用户是「生成空白模板」还是「对特定标的生成跟踪表」：
   - **生成空白模板**：输出通用的跟踪表设计说明（见 `references/tracking-template.md`）
   - **对特定标的**：根据该标的的行业属性和商业模式，生成具体量化的绿/黄/红灯条件

2. 跟踪表结构（每个标的一张）：

| 跟踪指标 | 绿灯 | 黄灯 | 红灯 |
|---------|:----:|:----:|:----:|
| [核心指标 1] | [条件] | [条件] | [条件] |
| [核心指标 2] | [条件] | [条件] | [条件] |
| [核心指标 3] | [条件] | [条件] | [条件] |

3. 同时生成退出条件模板：

```
买入时的退出条件预设：
- 如果（逻辑成立条件）→ 那么（目标价 / 持有时长估算）
- 如果（条件 A 破坏）→ 那么（退出时机 / 减仓比例）
- 如果（条件 B 破坏）→ 那么（完全退出）
```

4. **对于用户已有的持仓**，如果用户要求"帮我评估我的持仓"，先通过 tushare 或其他渠道获取最新财务数据，然后对照红绿灯条件逐条判断当前状态。

## 入口 6：完整流程（从宏观到个股到跟踪）

**匹配方式**：用户提到「完整流程」「从头走一遍」「帮我选股」「现在该买什么」「全面分析」等关键词时自动触发。

**流程**：

按顺序执行以下步骤：

```
步骤 1：宏观定位
→ 判定利率周期类型 → 输出当前宏观背景

步骤 2：降息传导链
→ 输出当前阶段板块优先级排序

步骤 3：行业三维定性
→ 结合当前背景锁定最有潜力的 1-2 个行业

步骤 4：四层筛子
→ 对选定的 2-3 个具体标的逐一执行四层筛子

步骤 5：红绿灯跟踪
→ 为通过筛选的标的生成跟踪指标和退出条件
```

**说明**：完整流程会产生较多内容，建议在用户明确要求"全面分析"时使用。平时更推荐按需调用细分入口。

## 与 Serenity Skill 的协作

```
用户消息 → 判断方向
   ├→ 宏观/赛道方向 → 本框架（investment-framework）
   │     ↓
   │   锁定赛道后，可接力 → Serenity Skill（在赛道内挖弹性标的）
   │
   └→ 一条消息/新闻/题材 → Serenity Skill（自下而上）
         ↓
       找到标的 → 可接力 → 本框架的四层筛子（验证逻辑硬度）
```

## 限制与注意事项

1. **宏观判断的时效性**：利率周期类型可能在短期内切换（如预防式→危机性），需要实时数据支撑
2. **本框架偏好中大盘+确定性**：倾向选择四层筛子全部通过的标的，天然忽略小市值不确定性标的——这是与 Serenity 的互补而非缺陷
3. **完整流程耗时长**：建议按需调用细分入口，避免无必要地跑完整流程
4. **不替代独立研究**：四层筛子需要用户/助手主动搜索行业数据填入依据，工具不保证覆盖所有维度的最新信息
