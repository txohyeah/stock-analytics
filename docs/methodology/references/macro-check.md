# 宏观判断检查清单

## 美联储降息的三种类型

### 1. 预防式降息

| 属性 | 内容 |
|------|------|
| 催化剂 | 经济放缓迹象，通胀可控 |
| 美股表现 | 较强，首次降息前后通常上涨 |
| 典型案例 | 1995 年 |
| 隐含前提 | 通胀已被控制，联储有余地预防性宽松 |

**识别要点**：
- 失业率从低位回升但仍在历史低位
- 通胀（核心 PCE）趋势向下或已在目标附近（~2%）
- 企业盈利尚可
- 股市在经过一段调整后企稳

### 2. 衰退式降息

| 属性 | 内容 |
|------|------|
| 催化剂 | 经济确认衰退，通胀已回落 |
| 美股表现 | 衰退区间下跌，降息效果显现后反弹（N 型） |
| 典型案例 | 1989 年 |
| 隐含前提 | 衰退已确认，降息是应对而非预防 |

**识别要点**：
- GDP 连续负增长或接近
- 失业率显著上升
- 企业盈利普遍下滑
- 消费者信心大幅走弱

### 3. 危机性降息

| 属性 | 内容 |
|------|------|
| 催化剂 | 金融/突发危机 |
| 美股表现 | 节奏快、时间短，解除后 V 型反转 |
| 典型案例 | 2008 年、2020 年 |
| 隐含前提 | 系统性风险，联储被迫紧急行动 |

**识别要点**：
- 突发性金融事件（银行倒闭、流动性枯竭等）
- 降息幅度大、节奏密集
- 通常伴随 QE 或其他非常规工具
- 市场恐慌指数（VIX）飙升

## ⚠️ 边界说明

三类降息在实战中并不总是泾渭分明。例如 2007-2008 年联储从 4.75% 降到 0%，早期是预防式尝试，随着贝尔斯登/雷曼崩塌加速转向危机性。

**以「降息全程的主导性质」而非首次降息来归类更贴近实际。**
