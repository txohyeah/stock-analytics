# 四层筛子评分细则与否决条件

> 本文档是 `00-framework.md` **步骤四**的细则。**三层结构**：
> - **四层筛子** = 淘汰制主流程（任何一层否决即筛掉）
> - **④b 参股价值重估** = 第四层补充分析，**不参与淘汰**
> - **估值安全边际检查** = 筛子**之外**的必做检查（不是"第 5 个筛子"），不参与淘汰，只防"好逻辑被过度定价"

这是淘汰制（而非加分制）——每一层筛掉不合格的候选。

```
卡脖子/格局壁垒 → 价值量最大/通胀逻辑 → 供需矛盾 → 利润弹性+壁垒延续
```

## 第一层：卡脖子 / 格局壁垒

### 问什么
是否具备全球竞争力的技术或市场壁垒？

### 通过的典型特征
- 全球范围内的寡头/双寡头位置
- 技术壁垒高（专利、工艺、认证门槛）
- 客户粘性强（更换成本高、认证周期长）
- 中国公司在该环节具备全球竞争力（不是勉强替代）

### 否决条件（任一成立则筛掉）
- 纯低价抢份额，无技术壁垒
- 纯代工/组装，核心技术依赖上游
- 客户极度集中且无粘性（随时可以被换）
- 壁垒靠政策保护而非真实竞争力

---

## 第二层：价值量最大 / 通胀逻辑

### 问什么
该环节在产业链中的价值占比是否大？随着技术升级，价值量是在提升还是在被压缩？

### 通过的典型特征
- 该环节占下游 BOM 比例较高
- 技术升级时该环节单价上涨（ASP 通胀）
- 产品升级带动用量增加（量价齐升）

### 否决条件（任一成立则筛掉）
- 价值量占比低且不受重视
- 技术升级反而压缩该环节价值（如集成化吃掉独立器件）
- 行业成熟期，产品持续降价且无升级路径

**关键洞察**：光模块不是 BOM 中最大的（GPU 才是），但 800G→1.6T 单价翻倍、且每服务器配的数量从 1:1 扩大到 1:4，实现了"量价齐升"。这才是"价值量通胀"的真正含义——绝对占比不够大没关系，关键是趋势方向。

---

## 第三层：供需矛盾

### 问什么
当前该环节是否供不应求？大客户是否已锁单/长约锁定产能？

### 通过的典型特征
- 行业产能利用率高（>90%）
- 交期延长
- 大客户签长协或预付
- 新进入者产能短期无法释放

### 否决条件（任一成立则筛掉）
- 产能严重过剩、库存高企
- 无定价权，毛利率走低
- 行业门槛低，大量新产能正在涌入

---

## 第四层：利润弹性 + 壁垒延续

### 问什么
未来 1-2 年的利润弹性有多大？竞争壁垒能否维持 3-5 年？

### 通过的典型特征
- 未来 2 年利润增速 >30%
- 技术/客户壁垒可以维持至少 3-5 年
- 即使竞争对手追赶，领先时间窗口够长
- 市场份额稳定或扩大

### 否决条件
- 利润可见性差（依赖不可预测的订单）
- 壁垒在 1-2 年内就会被追上
- 竞争格局在恶化（价格战启动）

> ⚠️ **多数人在「卡脖子」或「供需矛盾」就停了，但第四层筛掉了大量表面好看实则站在悬崖边的标的。这是确定性 EPS 驱动和题材炒作之间的分水岭。**

## 第四层补充：4b 参股价值重估

### 什么时候触发

仅在母公司持有重要参股标的时启用，不是必选项。触发门槛（**两项都满足**）：

| 条件 | 说明 |
|------|------|
| ① 持股比例 ≥ 10% | 太低则对公司价值影响有限，非并表参股以实际计入报表的权益为准 |
| ② 参股标的自身有价值 | **核心前提**。参股公司的主营有前景、有营收/利润、或处于高景气赛道。参股一个没前景、没盈利的破公司不值一提 |

**跳过条件（任一成立则不展开分析）：**
- 持股 < 10%
- 参股标的主业不明 / 持续亏损且无改善 / 所在行业衰退
- 参股标的全都是与母公司主业高度重合的同类公司（无额外价值）

---

### 分析四步走

#### 步骤 1：筛出重要参股

从财报/公告里梳理：
- 母公司持有的参股/控股子公司一览
- 按持股比例排序，只看 ≥ 10% 的部分
- 剔除：主业跟母公司完全重合、市值占比过小（< 5% 母公司市值）的参股

**工具**：tushare fina/balancesheet 查长期股权投资明细；web_search 搜公告。

```bash
# 查长期股权投资、对联营/合营企业投资（stock-analytics 数据层）
cd /home/application/stock-analytics
./venv/bin/python -m app.cli query balancesheet --ts-codes <code>  # 长期股权投资 longterm_equity_invest
```

#### 步骤 2：判断参股标的自身是否有价值（核心）

这是决定是否值得展开的分水岭。回答三个问题：

| 问题 | 检查项 |
|------|--------|
| 它的主业是什么？ | 是否处于高景气/政策支持的赛道？超导？AI？新能源？半导体？ |
| 它自己有营收/利润吗？ | 已盈利还是烧钱阶段？营收增速如何？可比上市公司 PE 多少？ |
| 它的行业地位如何？ | 市占率？技术壁垒？有没有独供/寡头卡位的特征？ |

结论三种：**有价值**（高景气赛道+有营收或明确商业化路径）/ **待观察**（赛道不错但仍在烧钱，盈利时间不确定）/ **无价值**（没前景的夕阳行业或持续亏损无改善）。

如结论为「无价值」，4b 分析到此为止，参股不构成加分因素，也不改变第四层原有的判断结论。

---

#### 步骤 3：量化隐含价值

按可比公司估值法估算参股标的的合理估值：

```
隐含价值 = 母公司持股份额 × 参股标的合理估值
```

**归母占比** = 隐含价值 ÷ 母公司总市值：

| 占比区间 | 意义 |
|---------|------|
| > 30% | **非常显著**——参股本身就是核心价值构成，必须重点讨论 |
| 10% ~ 30% | **值得注意**——参股对弹性有贡献，可作为额外加分 |
| < 10% | **参考信息**——可提及但不构成核心驱动 |

**注意**：如参股标的未上市，估值参考可比上市公司（考虑流动性折价 20-40%）。如已在上市进程中，参考 Pre-IPO 估值更新。

**工具**：
- 对比 tushare 行业板块 PE/PB 中位数
- 参照已上市公司市值进行可比估值
- web_search 搜最近融资轮估值

---

#### 步骤 4：判断价值解锁路径

| 路径 | 含义 | 对股价的催化力度 |
|------|------|----------------|
| IPO 申报/过会中 | 最明确的催化剂，上市后市值公开、母公司按权益法重估 | ★★★★★ |
| 计划分拆上市 | 已披露意向或进入准备期 | ★★★★ |
| 战略融资/引战投 | 第三方给出估值锚，有一定信号意义 | ★★★ |
| 暂无明确路径 | 价值可能长期被隐藏——除非参股标的价值自行兑现（分红/减持），否则市场不会主动定价 | ★ |

---

### 4b 输出模板

当触发分析时，在第四层结论后输出：

```
### ④b 参股价值重估 → ✅（有价值·加分）/ ⚠️（待观察）/ ➖（跳过·不适用）

| 项目 | 内容 |
|------|------|
| 参股标的 | [名称，主业简介] |
| 持股比例 | [X%] |
| 参股标的价值判断 | [有价值/待观察/无价值] |
| 隐含价值（母公司份额） | [XX 亿元] |
| 占母公司市值 | [X%] |
| 价值解锁路径 | [IPO申报中/计划分拆/融资引战中/暂无] |
| 对整体结论的影响 | [如参股标的有价值，则增强第四层判据；否则不改变结论] |
```

### 4b 不改变淘汰制

四层筛子本身是淘汰制，4b 是第四层的补充分析：

- **参股标的有价值 + 隐含价值显著（>30%）** → 增强第四层判断（原来通过的更强，原来因主业弹性不足被卡的，参股可能提供额外弹性）
- **参股标的有价值但规模不大** → 作为参考信息，不改变原有通过/不通过结论
- **参股标的无价值/跳过** → 不构成加分因素，完全回到四层原有结论

---

## 第五个考量（不在筛子内，但应在买入前评估）：估值安全边际

> ⚠️ 注意：这不是"第 5 个筛子"，不参与四层淘汰——**逻辑对但价格贵**不会把标的中途淘汰，而是影响买入时机与仓位。

在当前价格下，隐含的未来增速有多少已被市场定价？如果估值已充分反映甚至透支了预期，即使四层全过，也可能面临股价下跌——不是逻辑坏了，而是好逻辑被过分定价了。

建议在四层筛子后加一道估值检查：
- 当前 PE 对应的一致预期增速是多少？
- 如果增速不及预期 20%，股价最大回撤空间？
