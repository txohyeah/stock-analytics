
# 产业爆发（产业主脉·爆发形态）

产业主脉内部的两个形态之一——**产业刚过商业化拐点、报表刚开始放量兑现、渗透率仍在低位**的高弹性阶段。
本 skill 回答三个问题：**它是产业爆发吗**（识别）、**兑现到哪一步了**（跟踪）、**什么时候证伪/切换**（纪律）。

与 `stock-position-classification` 的关系：分类框架负责"归到产业主脉"，本 skill 负责"主脉内部是不是爆发形态 + 怎么操作"。
与 `stock-page-builder` 的关系：判定为产业爆发后，用 `explosion` 模板建页（`lineCat: "explosion"`，🔥 产业爆发 badge）。

## 触发方式

- 用户问「这是爆发还是主脉」「拐点到了吗」「报表放量了吗」
- 产业刚有里程碑级催化（监管获批/大订单/装机放量）+ 个股大涨，需判断是主脉兑现还是题材炒作
- 已归产业主脉的票，判断内部形态（爆发型 vs 现金牛型）
- 前瞻卡位票升级判断（P 高 + G 大 + 放量三者满足 → 升级为爆发型主脉）

## 核心定义

**产业爆发型主脉** = 产业拐点已到（✅ 已验证）+ 公司卡住核心位置（✅）+ **报表刚开始放量** + 渗透率仍在低位。

一句话：**风已经来了，报表刚开始起量，估值按爆发定价。**

对照一句话：
- 前瞻卡位 = 公司卡住了，**风还没来**（报表没起量）
- 技术短线 = 风来了，**公司没卡住**（吃边角料）
- 现金牛主脉 = 风来了很久，**渗透率已中高位**（报表稳增、PE 低）
- 夕阳龙头 = 风已经停了（产业萎缩，公司还卡着）

## 识别五信号（全部满足才算，缺一个回到相邻分类）

1. **拐点已确认**：有里程碑级证据落地（监管/临床获批、大客户平台订单实锤、装机/出货数据跳升），不是"即将落地"。
   反例：只有"预计 Q4 获批" → 前瞻卡位，不是爆发。
2. **报表开始兑现**：最新季报/半年报利润或收入增速显著提速（+20% 以上为佳），且市场预测未来 1-2 年继续加速（+30-40%）。
   反例：增速 5% 的"稳健" → 现金牛型；亏损且无起色 → 前瞻卡位或技术短线。
3. **渗透率仍在低位**：产业渗透率远未饱和，增长有 3 年以上可见度。渗透率过半 → 现金牛型。
4. **结构质变刚发生**（可选但强力）：经常性收入/新业务占比刚越过关键阈值（如按次分成占比过半、第二曲线收入超主业）。
5. **催化密集**：未来 1-2 个季度有多个可跟踪节点（FDA/上市/大订单/装机目标），不是一年一个的"远期故事"。

## 判定流程

```
产业已验证？ ──否──→ 前瞻卡位 / 题材博弈（看公司卡位）
   │是
公司卡住核心位置？ ──否──→ 技术短线（外溢受益型）
   │是
报表最新一期放量了？ ──否──→ 前瞻卡位（等风来，P/G/T 分级）
   │是
渗透率中高位？ ──否──→ 🔥 产业爆发型主脉（本 skill）
   │是
成熟现金牛型主脉（换现金牛纪律）
```

**关键分水岭只有一个：最新一期报表有没有放量。** 放量与否区分爆发 vs 前瞻卡位；渗透率+增速+估值三合一区分爆发 vs 现金牛。不看 PE 高低——爆发型 PE 高恰恰是市场认可主脉的证据，不是炒作证据。

## 操作纪律（与现金牛完全不同）

| 维度 | 产业爆发型 | 成熟现金牛型 |
|------|-----------|-------------|
| 买入 | **回调分批**（回踩波动下沿/支撑），**不追大阳线** | 区间内长持，跌了敢买 |
| 持有 | 主脉级仓位上限，但按成长股纪律 | 底仓长持 |
| 跟踪 | 兑现跟踪表逐季更新（订单/区域增速/渗透率） | 产业边际变化（红绿灯表） |
| 止损 | **证伪线触发即减仓**（连续两季增速掉头/里程碑推迟） | 逻辑破坏才退出 |
| 风险 | 预期跑在报表前面 → 杀估值（-30%+ 正常） | 产业见顶/地位侵蚀 |

**为什么不能当现金牛操作**：爆发型的估值锚是"未来 1-2 年加速兑现"，一旦兑现不及预期，杀的是估值不是业绩（forward PE 55x 杀到 30x = -45%）。"越跌越买"在现金牛是策略，在爆发型是接飞刀。

**为什么不能当前瞻卡位操作**：爆发型的催化已在报表里，按"等风来"的卫星仓小仓位持有，等于错过主升段。给主脉级仓位上限，但分批进场。

## 兑现跟踪表（每季更新，页面承载）

| 跟踪指标 | 看什么 | 证伪阈值 |
|----------|--------|---------|
| 核心区域/产品收入增速 | 是否延续加速（如美国区 +35%） | 连续两季掉头 |
| 订单/装机/出货量 | 里程碑兑现节奏（如泵月交付 400→1200 台） | 关键里程碑推迟 1 季以上 |
| 渗透率/市占率 | 仍在低位且提升 | 停滞 2 个季度 |
| 经常性收入占比 | 结构质变是否延续 | 回落跌破关键阈值 |
| 估值锚（forward PE） | 透支年数是否可控 | 透支 2 年以上增长 |

**形态切换（爆发 → 现金牛）**：渗透率进入中高位 + 增速自然回落至 10-20% → 切换为现金牛纪律（换低 PE 估值逻辑），不是卖出信号。

**证伪降级（爆发 → 技术短线/减仓）**：连续两季增速掉头 / 关键里程碑推迟（FDA、大订单落空）/ 竞争格局恶化（份额被抢）→ 按波段纪律处理或直接减仓。

## 案例

**福瑞股份 300049（2026-08-25 基准案例）**
- 拐点：美国 MASH 获批后产业逻辑确认，Echosens 美国区 +35%（欧洲获批晚 8 个月待复制）
- 报表：H1 收入 7.55 亿(+5.8%)、归母 0.64 亿(+23%)；按次分成占比 53% 首超销售业务（结构质变）
- 渗透率：MASH 检测全球渗透率起步，印度 6000+ 机构订单待落地（数亿美元级）
- 估值约束：forward PE ~55x（116 亿/全年 2.1 亿预测），已透支部分预期 → 回调分批不追高
- 证伪线：美国区增速连续两季掉头 / Sonovein FDA 推迟 / 股权问题再搁浅
- 切换点：欧洲复制美国增长 + 渗透率提升后增速回落 → 现金牛型
- 反例警示：2026-08 从 48 跌到 37（-22%）就是爆发型杀估值的预演——预期跑太快，回调深而急

**对照案例**
- 前瞻卡位对照：亚星锚链（漂浮式风电未兑现、报表未放量）→ 等风来，不是爆发
- 现金牛对照：紫金矿业（铜金渗透率中高位、PE 15x、稳增）→ 现金牛纪律，不是爆发
- 技术短线对照：算力租赁商（产业火、没卡住）→ 波段，不是爆发

## 与相邻分类的边界速查

| 对比 | 产业爆发型 | 前瞻卡位 | 技术短线 | 现金牛主脉 |
|------|-----------|---------|---------|-----------|
| 产业拐点 | ✅ 已到 | ❌ 未到 | ✅/❌ | ✅ 早到了 |
| 报表放量 | ✅ 刚放量 | ❌ 未兑现 | 看公司（外溢也有好业绩） | ✅ 稳增 |
| 公司卡位 | ✅ | ✅ | ❌ | ✅ |
| 渗透率 | 低 | 低 | 无关 | 中高位 |
| 估值 | 高（40x+） | 高（预期定价） | 高/题材 | 低（10-30x） |
| 操作 | 回调分批+证伪线 | 卫星仓等催化 | 波段+止损 | 区间长持 |
