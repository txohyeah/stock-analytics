
# 个股定位分类（产业主脉 / 前瞻卡位 / 技术短线 / 分红企业 / 夕阳龙头）

## 定位

这是 investment-framework（产业投资框架）的**输出归类层**：四层筛子回答"这家公司值不值得买"，本 skill 回答"它属于哪一类、按什么方式持有"。两者衔接使用——先跑四层筛子（或已有产业/公司分析），再按本 skill 归类。

## 触发方式

- 用户提到「算什么定位」「产业主脉还是技术短线」「属于哪一类」「怎么持有」等关键词
- 对个股完成四层筛子/基本面分析后追问归类
- 用户给出一段"产业+公司"分析要求归类（如"帮我看看它算哪类"）

## 核心模型：二维矩阵

归类 = 回答两个独立问题：

**问题 1：产业是否已验证？**
- ✅ 已验证：需求爆发/商业化拐点已到，收入利润已在报表兑现（如 2026 年的 AI 算力、存储涨价周期）
- ❌ 未验证：方向确立但兑现尚早，商业化拐点未到（如早期固态电池、临床早期的创新药管线）

**问题 2：公司是否卡住核心位置？**
- ✅ 卡住：四层筛子 ①卡脖子（有壁垒）且 ②价值量（环节价值大）通过
- ❌ 没卡住：无壁垒/靠低价抢份额/纯代工/租赁搬运工/后进追赶者

组合成 2×2（2026-08 新增第三行：产业过峰/趋势萎缩）：

| | 公司卡住核心位置 | 公司未卡住 |
|--|--|--|
| **产业已验证/向上** | **产业主脉**（细分为：**产业爆发型** / 成熟现金牛型，见下） | **技术短线**（外溢受益型） |
| **产业未验证** | **前瞻卡位** | **技术短线**（题材博弈型）/ 观望 |
| **产业已过峰/趋势萎缩** | **⑤ 夕阳龙头**（波段+吃息） | **技术短线**（过气题材）/ 回避 |

**独立维度：高分红** → 股息率≥2% + 大市值 + 低波动 = **分红企业**（成长类归类的替代选项，两套并存时按主导特征归类；若产业方向为趋势性萎缩，优先归**夕阳龙头**而非分红企业）

## 四类定义与判定细则

### ① 产业主脉

- **定义**：产业已验证 + 公司卡住核心位置，四层筛子通过
- **判定 checklist**：
  - [ ] 四层筛子 ①②③④ 全部通过
  - [ ] 产业趋势有可跟踪的量化指标（价格/出货/订单）
  - [ ] 公司在产业链中有定价权或客户锁定
- **操作含义**：特定 PE 区间内买入并**长持**；跟踪产业边际变化（红绿灯表），逻辑破坏才退出
- **升级/降级**：产业景气见顶 → 需重估周期位置；公司地位被侵蚀 → 重新跑四层筛子

#### 产业主脉的两个形态（2026-08-25 新增）

产业主脉不是一个均匀的篮子——**「产业已验证」覆盖从拐点刚过到渗透率中高位的整个区间**，两端的持有纪律完全不同。归主脉后必须再判形态：

| | **产业爆发型**（成长兑现期） | **成熟现金牛型**（稳态主脉） |
|---|---|---|
| 产业阶段 | **刚过商业化拐点**、渗透率起步（如美国 MASH 2025-26 获批后的检测链） | 商业化多年、渗透率中高位（如铜矿、证券 IT） |
| 报表特征 | 刚开始加速、收入或利润单腿放量、结构质变刚发生（如按次分成占比刚过半） | 收入利润稳增、结构稳定 |
| 估值 | PE 高（40x+），市场按"爆发"定价 | PE 低（10-30x），按"稳定"定价 |
| 波动 | 大（单日 ±5-15% 常见，题材化） | 小 |
| 操作 | **重跟踪兑现节奏，回调分批买，不追大阳线**；按成长股纪律 | 区间内长持，跌了敢买 |
| 主要风险 | **兑现不及预期 → 杀估值**（预期跑在报表前面） | 逻辑破坏 / 产业见顶 |

**产业爆发型判定 checklist**（全部满足才按爆发型纪律，否则回到成熟现金牛型）：
- [ ] **拐点已确认**：有监管/临床/订单级别的里程碑落地（如 MASH 获批、大客户平台订单实锤），不是"即将"落地
- [ ] **报表开始兑现**：最新季度/半年报利润或收入增速显著提速（如 +20% 以上），且市场预测未来 1-2 年继续加速（+30-40%）
- [ ] **渗透率仍在低位**：产业渗透率远未饱和，增长有 3 年以上可见度
- [ ] **业务结构质变刚发生**（可选但强力）：经常性收入/新业务占比刚越过关键阈值（如按次分成占比过半）
- [ ] **催化密集**：未来 1-2 个季度有多个可跟踪节点（FDA/港股/大订单/装机目标）

**爆发型 vs 前瞻卡位的边界**（最容易混）：爆发型是**拐点已到、报表已在兑现**（商业化拐点 ✅）；前瞻卡位是**拐点未到、报表未兑现**（商业化拐点 ❌）。判据就是一条：**最新一期报表有没有放量**。福瑞股份 2026H1 利润 +23%、全年 +40% 预测 = 已兑现 = 产业爆发型主脉；若还在等 MASH 获批、报表无起色 = 前瞻卡位。放量与否是唯一分水岭，不看 PE 高低（爆发型 PE 高恰恰说明市场已认可是主脉）。

**爆发型 vs 成熟现金牛型的边界**：产业渗透率阶段 + 报表增速 + 估值三合一判断。爆发型 PE 40x+/增速 30%+/渗透率起步；现金牛 PE 10-30x/增速 10-20%/渗透率中高位。判断错了操作就错——把爆发型当现金牛会"越跌越买"接飞刀（爆发型杀估值可以 -30%+），把现金牛当爆发型会追高站岗。

**爆发型操作纪律（核心）**：
- **名分**：产业主脉（公司卡住+产业验证），可给主脉级仓位上限
- **买入**：回调分批（如回踩 20-30% 波动的下沿/支撑位），**不追大阳线**（放量暴涨日不追）
- **跟踪**：按"兑现跟踪表"逐季盯订单/出货/区域增速/渗透率指标（见 stock-page-builder explosion 模板）
- **证伪线**：连续两季增速掉头 / 关键里程碑推迟（如 FDA、大订单落空）/ 竞争格局恶化 → 降级技术短线（波段纪律）或直接减仓
- **退出**：渗透率进入中高位、增速回落到现金牛区间 → 形态切换为成熟现金牛型（换低 PE 逻辑），不是卖出

### ② 前瞻卡位

- **定义**：产业方向已确立、兑现尚在途中 + 公司已卡准位置（四层筛子 ①②通过，③④未到兑现期）
- **判定 checklist**：
  - [ ] 公司壁垒真实（①通过）、环节价值量大（②通过）
  - [ ] 产业商业化拐点未到（收入利润未大规模兑现）
  - [ ] 有明确的产业成熟时间表/催化节点
- **操作含义**：提前布局，仓位管理 + 等待催化；产业成熟后自动升级为产业主脉
- **升级/降级**：产业兑现（收入利润放量）→ 升级产业主脉（注意升级后先按**产业爆发型**纪律操作，渗透率还低时别直接按现金牛长持）；公司掉队（壁垒被证伪/竞对超越）→ 降级技术短线
- **关键区分：双条件判定**（2026-08 新益昌案例后沉淀）——前瞻卡位是"公司卡住了、等产业来"，**必须同时满足两个方向性条件**：
  - ① **卡住的位置，风没来**：公司卡住的细分环节，其对应产业尚未兑现（看渗透率/兑现度，不是看"有没有这个故事"）
  - ② **风要来的位置，卡住了**：即将兑现的产业方向里，公司是核心玩家（市占/认证/客户锁定；"在产业链里" ≠ "卡住核心位置"）
  - 任一错位都不是前瞻卡位：卡住的位置风已来 → 是已兑现的小主脉/鸡肋；风要来的位置没卡住 → **技术短线（外溢受益型）**
  - 反面典型"**错位卡位**"：卡住的位置风已过 + 风口的位置没卡住（新益昌 2026-08：LED/Mini LED 固晶机国内龙头但产业已兑现、半导体封测国产替代未卡住 → 技术短线）
  - **判定三问**：① 它卡住的细分环节，产业到哪一步了？② 更大的产业风口里，它是不是核心玩家？③ 是"投入期亏损"还是"经营恶化"？（营收高增/费用前置/方向在兑现 → 可给名分；亏损扩大/高负债/主业塌方 → 降技术短线，别用"等风来"包装经营恶化。注：报表好 ≠ 卡位证明——好钱若来自存量主业而第二曲线未兑现，恰是高纯度前瞻卡位，如亚星锚链；好钱若来自第二曲线兑现，则已该升级产业主脉）
  - 对照正确样本：亚星锚链（全球系泊链双寡头 + 漂浮式风电未兑现 + 报表已盈利）——双条件全满足，才是高纯度前瞻卡位
- **关键区分：P/G/T 三级评分**（2026-08-20 新增）——双条件判定回答"是不是前瞻卡位"，P/G/T 评分回答"值多少仓位"。前瞻卡位内部质地可差一个数量级（都是"等风来"，但风的大小、来的概率、等多久完全不同），必须分级后才能定仓位：
  - **P 兑现可能性**（风来不来）：
    - 技术路线成熟度：实验室 → 中试 → 量产爬坡 → 规模化（技术风险递减）
    - 成本经济性：单位成本是否逼近/跌破替代方案临界点（平价拐点）
    - 催化节点明确性：有无可跟踪的时间表（招标/认证/装机目标/政策 deadline）
    - 公司卡位硬度：是否独家/双寡头、客户验证到哪一步
  - **G 兑现后成长性**（来了多大）：
    - 可及市场空间：渗透率成熟时该环节的价值量（TAM）
    - 成长持续性：**项目制一波流 vs 持续经营**——建设周期型（一次招标就完）与耗材/服务/复购型（兑现后年年有）估值逻辑完全不同，持续经营型才配长持
    - 公司可捕捉份额：终局市占率假设
  - **T 兑现节奏**（等多久）：距催化节点 <1 年 / 1-3 年 / >3 年——同样确定性，等待期翻倍年化减半，决定资金效率
  - **分级与仓位含义**：
    | 级 | 条件 | 操作 |
    |----|------|------|
    | **A 级（准主脉）** | P 高（路线成熟+成本平价+节点明确）+ G 大（空间大+持续成长） | 可给主脉级仓位等待，兑现信号出现直接换挡升级 |
    | **B 级（标准卫星）** | P 高 G 中，或 P 中 G 大 | 标准卫星仓（组合 20-30% 内），单票设上限 |
    | **C 级（观察仓）** | P 低，或 G 小 | 小仓位/观察名单，兑现不确定则按技术短线纪律 |
  - **升级逻辑修正**：升级产业主脉需 **P 高 + G 大 + 收入利润放量** 三者同时满足；**G 小但放量 = 兑现即巅峰**，按技术短线波段处理，别在顶部当主脉接盘（"放量"本身不是升级充分条件）。升级后默认按**产业爆发型**纪律操作，直到渗透率进入中高位再切换现金牛型
  - 评分示例：亚星锚链（P 中 + G 中偏大）→ B 级标准卫星仓；2023 年初光模块回头看（P 高 + G 大）→ A 级准主脉；早期固态电池（P 中低 + G 极大）→ B 偏 C 小仓等；脑机接口（P 低 + G 极大）→ C 级观察为主

### ③ 技术短线

- **定义**：非产业主脉、非前瞻卡位、非高分红企业——借产业外溢订单或题材轮动获益，自身稀缺性或稳定性不足
- **两类典型**：
  - **外溢受益型**（产业已验证但公司没卡住）：如算力租赁商、跨界追赶者、**错位卡位者**（卡住的位置已兑现、风口的位置没卡住，如新益昌）——产业红利真实但公司吃的是边角料，业绩可能不错但含金量低（高杠杆/现金流差/无壁垒）
  - **题材博弈型**（产业未验证且公司没卡住）：纯概念，无业绩支撑
- **判定 checklist**：
  - [ ] 四层筛子存在淘汰项（尤其 ①卡脖子）
  - [ ] 产业红利真实但公司环节价值低/可被资金复制
  - [ ] 波动大、杠杆高、现金流弱、内部人减持等信号
- **操作含义**：只做波段，不做长持；按题材仓上限管理；必须预设止损和离场信号
- **升级路径**（观察名单，全部满足才重估）：商业模式验证（现金流转正/负债率下降）+ 卡位升级（自研产品落地）+ 产业红利持续
- **注意**：技术短线 ≠ 垃圾股。业绩可以很好（如协创数据 2026H1 预增 +247%~340%），但归类的核心是"能不能长持"，不是"业绩涨多少"

### ④ 分红企业

- **定义**：每年股息率≥2%，市值大、波动稳，成熟的现金奶牛
- **判定 checklist**：
  - [ ] 近 12 个月股息率 ≥2%
  - [ ] 大市值 + 低波动（年化波动明显低于市场）
  - [ ] 盈利稳定、现金流充沛、分红可持续
- **操作含义**：底仓配置长期持有；PE 合理（历史区间低位）时买入
- **注意**：与成长类分类可并存（如"分红企业 + 产业主脉"），归类时按主导特征选一个；**若产业方向为趋势性萎缩，归⑤夕阳龙头而非分红企业**（产业方向决定能否长持，财务特征只决定分红厚度）

### ⑤ 夕阳龙头（口语：夕阳老登）【2026-08-23 新增】

- **定义**：产业总量**趋势性萎缩**（非周期波动）+ 公司仍**卡住核心位置** + 往往伴随高股息——但**操作上只做波段，不建长持仓**
- **一句话**：公司是好的，产业是没的。赚波段 + 吃股息，不赌 PE 修复
- **判定 checklist**：
  - [ ] 产业趋势性萎缩：产量/销量中枢下移持续 ≥3 年 + 消费代际变迁（关键区分：**周期底 vs 趋势底**——2013 白酒是周期底（塑化剂+三公消费，总量会恢复），2026 的白酒需判断是否已转为趋势萎缩（人口结构+代际饮酒习惯），判断错了方向整个框架就错）
  - [ ] 公司卡位真实：四层筛子 ①✅ ②✅（壁垒/价值量顶级，定价权仍在——批价高于出厂价）
  - [ ] 高股息 ≥2%（常见但非必需——产业萎缩且无分红的龙头同样按此类操作纪律）
  - [ ] 利润靠**份额提升 + 提价**维持，而非行业增长
- **与相邻分类的边界**：

| 对比项 | 分红企业 | 夕阳龙头 | 技术短线（外溢受益型） |
|--------|---------|---------|----------------------|
| 产业方向 | 稳定/成熟 | **趋势性萎缩** | 已验证（可能仍向上） |
| 公司卡位 | ✅（通常） | ✅ | ❌ |
| 持有方式 | 长持收息（底仓） | **波段/抢反弹** | 波段 |
| 核心风险 | 利率/股息率变化 | **估值中枢下移（价值陷阱）** | 无壁垒、红利可复制 |

- **操作含义**：
  - **默认不建长持仓**；仅在超跌/情绪冰点时抢反弹，波段离场（本质上是技术短线纪律）
  - 高股息是**下行保护**（4%+ 高息让下跌空间有底），适合「跌出来买、弹起来卖」，不适合「越跌越买」
  - **退出条件必须含产业指标**（批价/开瓶率/消费量阈值），不只看股价或股息——产业萎缩到龙头也扛不住（价格倒挂）时是价值陷阱，不是黄金坑
  - 收益预期：赚波段 + 股息，**放弃 PE 修复幻想**（防的是戴维斯双杀）
  - 特例：纯收息型资金（类债配置、能接受估值中枢长期下移）可小仓长持作为类债替代——但这是资金性质例外，不改变分类本身的操作默认值
- **升级/降级（观察名单）**：
  - **升级产业主脉**：产业重新向上（需求回暖 + 提价权恢复，类似 2016 白酒）+ 收入利润恢复双位数增长 → 重估为产业主脉/分红企业
  - **降级/淘汰**：价格倒挂（批价跌破出厂价，定价权受损）→ 价值陷阱确认，移出观察名单
  - **持续重估项**：提价权是否仍硬（能否提价覆盖销量下滑）+ 有无第二曲线转型（新型烟草式）
- **案例**：
  - **正确操作样本**：贵州茅台 2026——PE 19.5x 历史低位 + 股息 4.06% + 分红率 79%，但产业深度调整、利润连续负增长 → 按夕阳龙头纪律：波段/防御，不因「好公司 + 低估值」就切换成长逻辑长持
  - **反例警示（不必然死）**：菲利普莫里斯/奥驰亚——全球吸烟率萎缩但靠持续提价 + 新型烟草转型长期跑赢大盘 → 说明「夕阳」不必然价值陷阱，关键在提价权与转型，但**重估确认之前按波段纪律**
  - **价值陷阱对照**：产业萎缩 + 提价权失效（价格倒挂）的龙头 = 纯价值陷阱，越跌越买是灾难

## 多产线公司：逐线归类（2026-08-21 新增）

**触发**：公司有两条以上业务线、且各线处于不同产业阶段时，不再整体归一类，改为**逐线归类**。
（单一主线公司不适用本章，直接走上面的四类判定。）

### 为什么必须拆（单数假设的失真）

四类标签本质是「这份资产怎么持有」——长持/提前布局/波段/底仓，`持有策略是可分仓位、可并存的`。而现有模型把特征级判定硬绑到公司级（一公司一标签），对多产线公司必然失真：

- 归「产业主脉」→ 把未兑现的第二曲线当主脉长持+重仓，风口没来资金被锁死
- 归「前瞻卡位」→ 忽略基本盘现金流，低估它已是现金牛的事实
- 归「技术短线」→ 用波段纪律砍掉一个其实该长持的核心业务

> 现有 skill 内部已多处「半承认」此事实，只是没推到逻辑终点：①「分红企业 + 产业主脉可并存」已允许标签叠加；
> ② 亚星锚链案例（存量系泊链主脉 + 漂浮式风电前瞻卡位）本质就是两线；③ P/G/T 判定三问里「好钱来自存量主业、
> 第二曲线未兑现」本质就是「主脉 + 前瞻卡位」并存。真正的判定单位是**业务线**，不是法人。

### 三步流程

**① 拆线**：按业务线拆分，每条线独立跑 2×2 判定（产业是否验证 × 公司是否卡住）。

**② 加权**：给每条线标权重（收入占比 / 利润占比 / 远期价值），决定它在组合里拿多少注意力。
权重维度区分「**现值权重**」（当下业绩贡献，决定基本盘仓位）与「**远期权重**」（未来价值弹性，决定第二曲线该不该用卫星仓押注）。

**③ 复合处理**：公司级给一个**主导标签**（以对组合最重要的那条线定，供日常称呼/列表展示），但**红绿灯跟踪、P/G/T 分级、仓位纪律全部按线独立做**。两条线都重要则写复合标签（如「主脉 + 前瞻卡位」）。

### 必须警惕的一对对称陷阱

已有「错位卡位」防的是「卡住的位置风已过」，多线场景下要多防两个方向的**掩盖**：

| 陷阱 | 表现 | 处理 |
|------|------|------|
| **存量掩盖第二线空头** | 基本盘很强、第二曲线纯属概念 | 别因基本盘好就给第二线发「前瞻卡位」名分（第二线实为技术短线/题材，按波段纪律单独限量） |
| **第二线已兑现仍当前瞻卡位** | 第二曲线收入利润已实质放量，还在按「等风来」处理 | 用 P/G/T 升级逻辑升为第二条主脉（P 高 + G 大 + 收入利润放量三者同时），**并按产业爆发型纪律操作**（渗透率低、兑现初期） |

> 判断「第二线是不是真兑现」沿用 P/G/T：看该线自身收入/利润是否放量，不看公司整体报表（整体报表可能被存量主业稀释或粉饰）。
> 多产线里已放量的第二线：归**产业爆发型主脉**（如金力泰 2026 液冷收入预计 13-14 亿已超涂料主业、冰轮环境 IDC 冷水机组 7 月 1.4 亿美元订单），不要因「整体报表还小」而按前瞻卡位等风来。

## 常见误归类（重点）

1. **"业绩好 = 产业主脉"** ❌ → 业绩爆发可能是外溢受益（协创数据案例），关键看是否卡住核心位置
2. **"产业火 + 公司在产业链里 = 前瞻卡位"** ❌ → 前瞻卡位要求"公司卡住位置"这个前提；产业已兑现而公司没卡住 → 技术短线
3. **"技术短线 = 垃圾股"** ❌ → 技术短线是持有方式归类，业绩可以很好，关键是稀缺性/稳定性不足
4. **"分红企业只看股息率"** ❌ → 还要看分红可持续性（现金流、盈利稳定性）与低波动
5. **"公司是某环节龙头 = 前瞻卡位"** ❌（2026-08 新益昌案例）→ 还要问：这个环节的风来没来（渗透率/兑现度）？更大的风口它卡没卡住（市占/认证/客户）？**错位卡位**（卡住的位置已兑现 + 风口的位置没卡住）→ 技术短线（外溢受益型），别发前瞻卡位名分
6. **"所有前瞻卡位一样处理"** ❌（2026-08-20 P/G/T 新增）→ 双条件判定只是入门券，A/B/C 分级决定仓位上限：A 级可主脉级等待、B 级卫星仓、C 级观察仓。不分级就统一给仓位，等于用主脉的期望去赌 C 级的胜率
7. **"一公司 = 一分类"（多产线整体归类）** ❌（2026-08-21 新增）→ 多产线公司各线产业阶段不同，持有策略须按线分车位。整体归一类会：把未兑现的第二曲线当主脉重仓（锁死资金）、或忽略已兑现基本盘的现金流。正确做法见「多产线逐线归类」章节。典例：恒生电子 = 证券/基金交易系统（产业主脉）+ 金融大模型（第二线，按 P/G/T 单列仓位），不是单一卡死的一类
8. **"好公司 + 低估值 + 高股息 = 分红企业/产业主脉，可以长持"** ❌（2026-08 茅台案例）→ 必须先判断产业方向：产业**趋势性萎缩**时，质地再好也只配「夕阳龙头」的波段纪律（或纯收息型资金的小仓类债例外）。「公司卡住」解决的是「会不会死」，不解决「值不值得长持」；「值不值得长持」由产业方向决定。
9. **"所有产业主脉一样对待"** ❌（2026-08-25 新增，福瑞股份案例）→ 产业主脉内部必须分形态：**产业爆发型**（拐点刚过、报表刚放量、PE 高、波动大——重跟踪兑现、回调分批、不追高、设证伪线）vs **成熟现金牛型**（渗透率中高位、报表稳增、PE 低——区间长持、跌了敢买）。把爆发型当现金牛 → 越跌越买接杀估值的飞刀；把现金牛当爆发型 → 追高站岗。放量与否是爆发型 vs 前瞻卡位的分水岭，渗透率阶段+报表增速+估值三合一是爆发型 vs 现金牛的分水岭。

## 与 investment-framework 的衔接

- 入口 4（四层筛子）→ 本 skill 归类 → 入口 5（红绿灯跟踪）为产业主脉/前瞻卡位生成跟踪表
- 前瞻卡位（A/B 级）生成**前瞻卡位跟踪表**：催化节点 + 升级/降级信号（stock-page-builder frontier 模板承载）；技术短线标的用"波段跟踪表"（进出场信号+止损线）
- **产业爆发型主脉**：stock-page-builder explosion 模板承载「拐点核验 + 兑现跟踪表 + 证伪线 + 估值约束」（lineCat=`explosion`）
- **夕阳龙头**：四层筛子 ①✅ ②✅ + ③④ 因产业萎缩不通过 + 高股息 → 归类夕阳龙头；红绿灯跟踪表按「波段跟踪表」建立（进出场信号 + 止损线 + **产业指标阈值**），不按长持跟踪表
- 多产线标的：四层筛子**每条线分别跑**（线间的卡位/壁垒/价值量独立评估），红绿灯跟踪表**按线建立**（每条线一套指引），对应 stock-page-builder 的「主线 + 副线」结构（见 stock-page-builder skill）
