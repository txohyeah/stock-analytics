# 跟踪体系（红绿灯 / 兑现跟踪 / 催化跟踪 / 波段跟踪）

> `00-framework.md` **步骤六**的展开。核心不是"告诉我这公司好不好"，而是"**告诉我逻辑什么时候被破坏**"。
> 跟踪表在**买入时设计、持续更新**——逻辑链变了，操作跟着变。

## 一、四类跟踪表怎么选

| 持仓类型 | 用哪张表 | 盯什么 | 权威来源 |
|---------|---------|--------|---------|
| 任何持仓（通用） | **红绿灯表** | 核心指标的绿/黄/红三档，逻辑破坏预警 | 本文档 §二 |
| 产业爆发型主脉 | **兑现跟踪表** | 订单/出货/区域增速/渗透率逐季验证兑现节奏，设证伪线 | `02-industry-explosion.md`（本文档不重复） |
| 前瞻卡位（A/B 级） | **催化跟踪表** | 催化节点 + 升级（放量）/降级（掉队）信号 | 本文档 §三 |
| 技术短线 / 夕阳龙头 | **波段跟踪表** | 进出场信号 + 止损线（夕阳龙头另加产业指标阈值） | 本文档 §三 |

> 关系一句话：红绿灯是**通用底线**（任何持仓都该有），兑现/催化/波段是**分类专用**（按「怎么持有」匹配纪律）。爆发型主脉**同时**要红绿灯（防逻辑破坏）+ 兑现跟踪表（验证节奏）。

## 二、通用红绿灯跟踪表

### 设计步骤

1. 判断是「生成空白模板」还是「对特定标的生成跟踪表」：
   - 空白模板：给出本例通用结构
   - 特定标的：根据行业属性和商业模式，生成**具体量化**的绿/黄/红灯条件（阈值可查可验证，不用模糊表述）
2. 每个标的一张表：
3. 同时生成**退出条件预设**（买入时就写清楚）

### 通用模板

**头部信息**：

| 项目 | 内容 |
|------|------|
| 标的代码 + 名称 | |
| 逻辑定性 | 主业成长性行业，爆发式需求/存量变革/格局变化 |
| 重要性 | 核心仓位 / 一般仓位 / 观察标的 |
| 预估启动时点 | 产能投产 / 订单窗口 / 财报节点 |
| 逻辑 | 买入的完整逻辑链 |
| 财务数据及估值 | 当期财务数据、估值水平 |

**红绿灯指标表**：

| 跟踪维度 | 具体指标 | 🔴 红灯 | 🟡 黄灯 | 🟢 绿灯 |
|---------|---------|:-------:|:-------:|:-------:|
| 收入端 | [核心营收指标] | [证伪条件] | [警告条件] | [正常区间] |
| 利润端 | [核心利润指标] | [证伪条件] | [警告条件] | [正常区间] |
| 竞争格局 | [竞争监测指标] | [证伪条件] | [警告条件] | [正常区间] |
| 产业链 | [上下游指标] | [证伪条件] | [警告条件] | [正常区间] |
| 估值 | [估值指标] | [证伪条件] | [警告条件] | [正常区间] |

**退出条件预设（买入时写死）**：

```
> 如果（逻辑成立条件）→ 那么（目标价 / 持有时长估算）
> 如果（条件 A 破坏）→ 那么（退出时机 / 减仓比例）
> 如果（条件 B 破坏）→ 那么（完全退出 / 止损价）
```

### 示例：中际旭创跟踪表（光模块，AI 算力链）

**逻辑定性**：高端光模块（800G/1.6T）；爆发式需求（AI 算力）+ 存量技术变革（传统 DC→AI DC）+ 参与者变化（地缘下中国光模块全球地位加强）。重要性：核心仓位。

| 跟踪指标 | 🔴 红灯 | 🟡 黄灯 | 🟢 绿灯 |
|---------|:-------:|:-------:|:-------:|
| 季度营收同比增速 | <50% | 50-80% | >80% |
| 800G 光模块出货均价 | 下跌 >10% | 下跌 <5% | 环比持平或上涨 |
| 英伟达 Capex 指引 | 下调 | 持平 | 上调 |
| 竞争动态（新易盛/天孚） | 大客户分流 | 竞争对手份额小幅提升 | 旭创份额稳定或扩大 |
| 库存周转天数 | 显著增加 | 小幅增加 | 稳定或下降 |

**退出条件预设**：
- 逻辑成立：AI 算力需求持续 → 800G/1.6T 出货符合预期 → 持有
- 条件 A（减仓到半仓）：季度营收增速连续 2 个季度低于 50%
- 条件 B（完全退出）：英伟达下调 Capex 指引 或 大客户分流给竞争对手

### 不同行业的跟踪指标设计思路

| 行业类型 | 核心跟踪方向 | 常用跟踪指标 |
|---------|------------|------------|
| AI 硬件 | 出货量、客户 Capex、ASP | 营收增速、客户指引、均价 |
| Biotech / 创新药 | 管线进度、融资环境 | XBI 指数、临床进度、license-out |
| 家电/家具出口链 | 美国地产、汇率、关税 | 美国新屋开工、人民币汇率、关税政策 |
| 工业金属 | 库存、下游开工率 | LME 库存、加工费、开工率 |
| 半导体（设备/材料） | 资本开支、国产化率 | 晶圆厂 Capex、国产替代率、验证进度 |

对特定标的生成红绿灯表：先判行业 → 套用核心跟踪维度 → 按公司业务模式和竞争地位调整具体阈值。

## 三、分类专用跟踪表

### 前瞻卡位催化跟踪表（A/B 级）

盯的是**风什么时候来**：

| 跟踪项 | 内容 |
|--------|------|
| 催化节点 | [审批/招标/认证/装机目标/政策 deadline]，含预计时间 |
| 兑现信号（升级） | 该线收入/利润**放量**（对应线级，不看公司整体报表）+ P 高 + G 大 → 升级产业主脉（按爆发型纪律） |
| 降级信号 | 壁垒被证伪（竞对超越/认证丢单）/ 经营恶化伪装（亏损扩大、高负债、主业塌方）→ 降级技术短线 |
| 仓位约束 | A 级可主脉级仓位等待；B 级卫星仓；C 级观察名单 |

### 波段跟踪表（技术短线 / 夕阳龙头）

| 跟踪项 | 内容 |
|--------|------|
| 进出场信号 | [量价/情绪指标]：进场触发、离场触发 |
| 止损线 | [价格或信号位]，硬性执行 |
| 题材仓上限 | 单票/总题材仓位上限 |
| （夕阳龙头专属）产业指标 | 批价/开瓶率/消费量阈值——产业萎缩到龙头也扛不住（价格倒挂）= 价值陷阱，即时离场 |

## 四、多产线：按线建表

多产线标的的跟踪表**按线建立**（每条线一套），对应 `01-position-classification.md` 多产线章节的逐线归类。线间的红绿灯独立判断，公司级只做汇总展示。
