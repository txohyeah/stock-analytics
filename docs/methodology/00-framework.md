# 投资方法论总框架（自顶向下闭环）

> **一句话**：先看大局（宏观利率周期）→ 定赛道（降息传导 + 行业三维定性）→ 选个股（四层筛子）→ **归类**（五类定位分类，决定怎么持有）→ 持续跟踪（红绿灯/兑现/催化，预设退出条件），形成闭环。
>
> 本文档是整套方法论的**导航与骨架**：每步只给流程与关键结论，细则在对应专题文档，不重复展开。

## 一、怎么用（决策入口）

## 二、完整流程（六步闭环）

```
┌─────────────────────────────────────────────────────────┐
│ 步骤一 宏观定位                                          │
│   判定利率周期类型（预防式/衰退式/危机性）→ 输出宏观背景   │
│   → 细节: references/macro-check.md                      │
├─────────────────────────────────────────────────────────┤
│ 步骤二 降息传导链                                        │
│   科技/医药 → 地产/耐用消费品 → 资源品（传导顺序）        │
│   → 输出当前阶段板块优先级排序                            │
├─────────────────────────────────────────────────────────┤
│ 步骤三 行业三维定性                                      │
│   爆发式需求 × 存量技术变革 × 参与者变化                  │
│   → 结合宏观背景锁定最有潜力的 1-2 个行业                 │
├─────────────────────────────────────────────────────────┤
│ 步骤四 四层筛子（个股评估，淘汰制）                      │
│   ①卡脖子 → ②价值量 → ③供需 → ④利润弹性+壁垒延续        │
│   （+ ④b 参股重估 + 估值安全边际检查，不参与淘汰）        │
│   → 细节: references/four-layer-sieve.md                 │
├─────────────────────────────────────────────────────────┤
│ 步骤五 定位归类（决定"怎么持有"，本框架的落点）           │
│   2×2 矩阵 → 五类定位 → 主脉再判形态（爆发/现金牛）       │
│   → 多产线逐线归类；前瞻卡位 P/G/T 分级                   │
│   → 细节: 01-position-classification.md                  │
│   → 爆发形态细节: 02-industry-explosion.md               │
├─────────────────────────────────────────────────────────┤
│ 步骤六 跟踪与退出（逻辑破坏预警，买入时预设退出条件）     │
│   通用红绿灯 + 爆发型兑现跟踪表 + 前瞻卡位催化跟踪         │
│   → 细节: 03-tracking.md                                 │
└─────────────────────────────────────────────────────────┘
   ↑ 任一环节结论变了 → 重跑对应步骤（升级/降级/形态切换）
```

> **说明**：完整流程内容多，仅用户明确要求"全面分析"时跑。日常按需调用单步。

## 三、各步骤关键内容（精简版）

### 步骤一：宏观定位

获取 10 年期美债、联邦基金利率、CPI/核心 PCE、失业率、布伦特原油等数据，对照三类降息区分标准（详见 `references/macro-check.md`）：

- **预防式降息** — 经济放缓迹象但通胀可控，美股较强（如 1995）
- **衰退式降息** — 经济确认衰退，通胀已回落，美股 N 型（如 1989）
- **危机性降息** — 金融/突发危机，节奏快时间短，V 型反转（如 2008、2020）

输出：当前判定 + 关键条件变量 + 路径依赖（基准/转换场景/转换边界）。

### 步骤二：降息传导链

```
科技 / 医药   →   地产 / 耐用消费品   →   资源品
（最先受益）       （传导次之）            （滞后但弹性大）
```

| 板块 | 传导逻辑 | A 股映射 |
|------|---------|---------|
| 科技/医药 | 融资成本下降，一级市场投融资回暖 | Biotech/创新药（XBI 先行指标）、AI 硬件（光模块） |
| 地产/耐用消费品 | 长端利率回落→美国地产回暖→出口拉动 | 家电/家具/建材对美出口链 |
| 资源品 | 降息需求改善+美元走弱 | 铜铝工业金属（注意油价变量） |

> 特殊环境（如油价地缘变量）需标注对资源品内部的错位影响。

### 步骤三：行业三维定性

| 维度 | 问什么 |
|------|--------|
| ① 爆发式需求 | 行业需求是否在爆发增长？（如 AI 训练算力）增速最快但最拥挤 |
| ② 存量技术变革 | 是否有明确存量替代逻辑？（如燃油车→新能源）替代逻辑清晰、空间可测算 |
| ③ 参与者变化 | 行业格局是否突变？（如地缘导致的国产替代）格局变局通常有定价权溢价 |

**特别判断**：一个行业同时沾三个维度（如 AI 硬件）= 结构性强势的根本原因。

### 步骤四：四层筛子（详见 `references/four-layer-sieve.md`）

四层递进筛选，**淘汰制**（任一不通过即标记不通过）：

```
① 卡脖子/格局壁垒 → ② 价值量最大/通胀逻辑 → ③ 供需矛盾 → ④ 利润弹性+壁垒延续
```

附加（不参与淘汰）：④b 参股价值重估（仅≥10%持股且有价值时触发）、估值安全边际检查（买入前必做，看好逻辑是否被过度定价）。

> **⚠️ 使用纪律**：只问了估值/基本面对比（如"中际旭创 PE 多少"）直接用数据查询（stock-analytics CLI），不要跑完整四层筛子——四层筛子有分析成本，不在简单查询上滥用。

### 步骤五：定位归类（详见 `01-position-classification.md`）

四层筛子回答"值不值得买"，归类回答"**属于哪一类、按什么方式持有**"。

**2×2 总图**（产业是否验证 × 公司是否卡住核心位置）：

| | 公司卡住核心位置 | 公司未卡住 |
|--|--|--|
| **产业已验证/向上** | **产业主脉**（爆发型 / 现金牛型） | **技术短线**（外溢受益型） |
| **产业未验证** | **前瞻卡位** | **技术短线**（题材博弈型）/ 观望 |
| **产业已过峰/趋势萎缩** | **⑤ 夕阳龙头**（波段+吃息） | **技术短线**（过气题材）/ 回避 |

独立维度：高股息（≥2% + 大市值 + 低波动）= **分红企业**；与成长类并存时按主导特征归类，产业趋势性萎缩时优先归夕阳龙头。

**产业主脉必须再判形态**（决定操作纪律）：

| | 产业爆发型 | 成熟现金牛型 |
|---|---|---|
| 产业阶段 | 刚过商业化拐点、渗透率起步 | 商业化多年、渗透率中高位 |
| 报表特征 | 刚放量提速、结构质变刚发生 | 稳增、结构稳定 |
| 估值/波动 | PE 高（40x+）、波动大 | PE 低（10-30x）、波动小 |
| 操作 | 重跟踪兑现节奏、回调分批、不追大阳线、设证伪线（见 `02-industry-explosion.md`） | 区间内长持、跌了敢买 |

**分水岭（一句话）**：最新一期报表有没有放量——放量与否区分爆发 vs 前瞻卡位；渗透率+增速+估值三合一区分爆发 vs 现金牛。不看 PE 高低（爆发型 PE 高恰是市场认可的证据）。

### 步骤六：跟踪与退出（详见 `03-tracking.md`）

三种跟踪按持仓类型选用：
- **通用红绿灯**（任何持仓）：核心指标 绿/黄/红 三档，专盯"逻辑什么时候被破坏"
- **兑现跟踪表**（爆发型主脉）：逐季盯订单/出货/区域增速/渗透率，设证伪线
- **前瞻卡位催化跟踪**（A/B 级）：催化节点 + 升级/降级信号；技术短线/夕阳龙头用**波段跟踪表**（进出场+止损）

退出条件在**买入时预设**：逻辑成立→怎么持有；条件 A 破坏→减仓多少；条件 B 破坏→完全退出。

## 四、与相邻 skill / 数据层的协作

```
用户消息 → 判断方向
   ├→ 宏观/赛道方向 → 本框架（步骤一~四）
   │     ↓ 锁定赛道后
   │    （可选）Serenity 自下而上在赛道内挖小市值弹性标的
   │
   └→ 一条消息/新闻/题材 → Serenity skill（自下而上）
         ↓ 找到标的
        → 本框架步骤四（四层筛子验证逻辑硬度）→ 步骤五归类 → 步骤六跟踪
```

- **数据层**：行情/财务/估值全部走 stock-analytics（tushare 同步 → sqlite → `app.cli` 查询），不再直接调 tushare 脚本
- **建页承载**：归类与跟踪结果可落到个人收藏站（stock-page-builder）——`explosion` 模板承载爆发型兑现跟踪表、`frontier` 模板承载前瞻卡位跟踪、主线+副线结构对应多产线逐线归类

## 五、限制与注意事项

1. **宏观判断有时效性**：利率周期类型短期可切换（预防式→危机性），需实时数据支撑
2. **框架偏好中大盘+确定性**：倾向四层筛子全过的标的，天然忽略小市值不确定性——与 Serenity 互补而非缺陷
3. **完整流程耗时长**：按需调用单步，避免无谓跑全流程
4. **不替代独立研究**：四层筛子/归类的依据需要主动搜索行业数据填充，框架不保证覆盖最新信息
5. **归类是动态的**：产业方向、兑现进度、公司卡位都会变——升级/降级/形态切换要按观察名单持续重估（见 `01-position-classification.md` 各分类的升级/降级条件），不做一次性标签
